# Issue #75 — sticky guide filters + icon labels

Выполнил UX-полировку справочника карт в `index.html`:

- закрепил только строку фильтров справочника;
- оставил поле поиска обычным, без sticky;
- заменил текстовые подписи фильтров на компактные иконки;
- сохранил `aria-label` и `title` для доступности;
- не трогал поведение `Все`: очистка поиска, `blur()` клавиатуры и возврат полного списка;
- не менял Firebase counter, share canvas, fullscreen navigation, избранное, `Наверх`, mappings и `localStorage`-ключи.

Изменённый файл:

- `index.html`

Проверки:

- `git diff --check`
- статическая проверка разметки и поведения справочника по `index.html`
- `package.json` в репозитории отсутствует, поэтому `npm run check`, `npm test`, `npm run build` недоступны

Smoke-test:

- фильтры справочника визуально компактнее;
- строка фильтров закреплена отдельно от поиска;
- для фильтров сохранены доступные подписи;
- логика `Все` по коду остаётся прежней.

Blockers:

- полный визуальный мобильный smoke-test в этой среде не удалось завершить: headless Chrome на Windows стабильно падал на GPU-процессе при попытке рендера страницы, поэтому self-merge отложен до ручной проверки PR.
