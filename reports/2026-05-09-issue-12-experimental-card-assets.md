# Отчет по Issue #12

Дата: `2026-05-09`

## Что сделано

- В приложение добавлены экспериментальные наборы карт:
  - `pixel-tarot` — полный пиксельный набор `78/78`.
  - `veil-of-fate` — частичный набор `38` локальных файлов с fallback на `rws-classic`.
  - `major-pixel-jcanabal` — `22` старших аркана с fallback на `rws-classic`.
  - `major-pixel-zune` — `22` старших аркана с fallback на `rws-classic`.
- В `index.html` добавлен маппинг `card.id -> image` для экспериментальных колод без изменения базовой структуры статического приложения.
- Выбор колоды продолжает сохраняться в `localStorage` по ключу `tarot-card-deck-id`.
- Для partial и major-only наборов добавлен безопасный каскадный fallback на `rws-classic`.
- Для пиксельных наборов добавлен `image-rendering: pixelated`.

## Fullscreen и карточка результата

- В fullscreen теперь показывается роль карты:
  - `Карта дня` для дневного режима.
  - Название позиции для режима вопроса.
- Бейдж `Перевернутая` показывается только для реально перевернутой карты.
- Поворачивается только изображение, а не текст.
- Закрытие fullscreen работает:
  - по фону,
  - по `Escape`,
  - по клику на увеличенную карту.
- Если изображение в fullscreen не загрузилось, показывается fallback без поломки UI.

## Ограничения проверки

- На этой машине `Chrome --dump-dom` не вернул DOM-вывод для автоматизированного статического preview, поэтому полноценная headless DOM-проверка mobile/fullscreen не была надежно завершена через CLI.
- Из-за этого browser-проверка отмечена как частично ограниченная средой, без изменения самого приложения.

## Ожидаемый результат для пользователя

- В селекторе колод доступны экспериментальные наборы.
- Неполные наборы не ломают приложение и добирают отсутствующие карты из `rws-classic`.
- Fullscreen показывает ту же колоду и ту же ориентацию, что и карточка результата.
