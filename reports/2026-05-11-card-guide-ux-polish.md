## Что изменено

- Добавлена компактная кнопка «Наверх» в справочнике карт.
- Убраны фон и обводка у кнопки избранного, звезда стала спокойнее и чуть крупнее.
- Добавлена ненавязчивая подсказка «Клик по карте открывает полный просмотр.»
- Разделены клики по карточке, описанию и звезде.
- Для fullscreen из справочника добавлен режим `guide-mode` с более компактным и читаемым текстом.
- Навигация fullscreen внутри справочника теперь работает по текущему filtered list.

## Навигация в справочнике

- Клик по карточке открывает fullscreen.
- Клик по описанию раскрывает и сворачивает details без открытия fullscreen.
- Клик по звезде работает только как избранное.
- Возврат из fullscreen в справочник сохраняет текущий фильтр.
- Счетчик fullscreen показывает позицию внутри текущего списка, например `1 / 22`.
- Для первой и последней карточки выбран подход с отключением перехода за границы текущего списка.
