# Отчет: Polish fullscreen card share screen

Дата: 2026-05-10

## Задача

Issue: https://github.com/KostGame/Tarot/issues/16

Нужно сделать полноэкранный просмотр карты более аккуратным для мобильного экрана и скриншота: убрать технический вид, сократить пустоты, приблизить текст к карте, добавить действие «Поделиться» и исправить маленькое отображение pixel-колоды.

## Что изменено

- Полноэкранный просмотр собран в единый компактный блок: верхняя строка с позицией и закрытием, затем крупная карта, название, бейдж перевернутой карты, описание и нижняя кнопка.
- Изображение карты теперь находится внутри стабильного `.lightbox-card-frame` с `aspect-ratio` и `object-fit: contain`.
- Исправлена проблема pixel-колоды: маленькие исходные изображения больше не показываются в натуральном размере, а масштабируются внутри полноэкранного фрейма.
- Описание вынесено в читаемый блок с внутренней прокруткой для длинного текста.
- Добавлена кнопка «Поделиться»:
  - использует `navigator.share()`, если доступен;
  - иначе копирует текст карты и ссылку через Clipboard API;
  - если копирование недоступно, показывает понятное уведомление.
- Поворот перевернутой карты по-прежнему применяется только к изображению.

## Проверки

- `git diff --check` — пройдено.
- JS-синтаксис inline-скрипта проверен через `new Function(...)` в Node.js — пройдено.
- Статическая проверка наличия fullscreen-frame, share-кнопки, `navigator.share`, clipboard fallback и CSS для pixel deck — пройдена.
- `package.json` отсутствует, поэтому `npm run check`, `npm test`, `npm run build` не запускались.
- Playwright в локальном Node REPL недоступен, `msedge`/`chrome` CLI в PATH не найдены, поэтому полноценная браузерная проверка мобильного экрана из текущего окружения не выполнена.
