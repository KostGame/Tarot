## Что изменено

1. В верхнюю часть приложения добавлен выбор стиля карт.
2. Подключены только безопасные варианты:
   - `rws-classic` - базовая Rider-Waite-Smith колода из локальных файлов `assets/cards/`;
   - `rws-dark-classic` - темная CSS-обработка той же локальной колоды.
3. Выбор сохраняется в `localStorage` по ключу `tarot-card-deck-id`.
4. Значение по умолчанию: `rws-classic`.
5. При смене стиля уже показанная карта и лайтбокс обновляют путь изображения через общий helper.
6. Нижний блок настроек заменен на компактную пиктограмму `⚙`; раскрытая панель с настройкой перевернутых карт сохранена.
7. Добавлен документ `docs/ASSET_CANDIDATES.md` со списком кандидатов из комментария Issue.
8. Сомнительные и неполные candidate decks не подключены в UI.

## Реализация выбора колоды

- Список доступных вариантов хранится в массиве `cardDecks`.
- `rws-classic` использует текущие локальные пути `assets/cards/*.jpg`.
- `rws-dark-classic` использует те же файлы и CSS-класс `deck-rws-dark-classic`.
- При загрузке приложение читает `localStorage.getItem("tarot-card-deck-id")`.
- Неизвестное или отсутствующее значение нормализуется к `rws-classic`.
- При изменении select приложение записывает выбранный id в `localStorage`, меняет CSS-класс `body` и обновляет уже отрендеренные изображения.
