# Egyptian Tarot / Falconnier Mapping

Deck id: `egyptian-falconnier`

Status: historical experimental major-only deck, connected in UI as `major-only`.

## Source

- Commons category: [Egyptian Tarot (Falconnier)](https://commons.wikimedia.org/wiki/Category:Egyptian_Tarot_(Falconnier))
- Source pack used in the app: 22 locally downloaded PNG major arcana cards.
- The general `Egyptian-tarot.jpg` file is intentionally not used as a card asset.
