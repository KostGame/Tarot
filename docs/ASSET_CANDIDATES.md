# Asset Candidates

Дата фиксации списка: 2026-05-09.

Этот документ хранит кандидатов на будущие визуальные наборы карт. В текущей версии приложения в интерфейс подключены только безопасные варианты:

- `rws-classic` - базовая Rider-Waite-Smith колода из локальных файлов `assets/cards/`.
- `rws-dark-classic` - темная CSS-обработка той же локальной колоды без дополнительных ассетов.

Остальные наборы ниже не подключены в UI и требуют ручной проверки лицензии, полноты колоды, качества изображений и совместимости с мобильной версткой.

## Подключено

### Rider-Waite-Smith / rws-classic

- Статус: подключено как базовая колода.
- Источник текущих файлов: Wikimedia Commons category Rider-Waite-Smith tarot deck (TaionWC).
- Локальные ассеты: `assets/cards/`.
- Документация источника: `assets/cards/README.md`.
- Причина выбора: полный набор 78 карт, понятная структура, локальное хранение без runtime hotlink.

### Rider-Waite-Smith dark preset / rws-dark-classic

- Статус: подключено как CSS-пресет поверх `rws-classic`.
- Дополнительные файлы карт: не используются.
- Причина выбора: безопасный темный вариант без подключения сомнительных или непроверенных наборов.

## Кандидаты для ручной проверки

### Rider-Waite Smith Tarot Cards CC0 by LuciellaES

- Статус: кандидат на альтернативный RWS-набор.
- Источник: https://luciellaes.itch.io/rider-waite-smith-tarot-cards-cc0
- Предварительная оценка: полный набор 78 карт, заявлен CC0.
- Форматы из комментария Issue: JPG 300x527, PNG, card border.
- Перед подключением проверить: страницу проекта, архив, фактические файлы, метаданные лицензии, совпадение всех 78 карт.
- Примечание: может быть использован как источник для будущего обновления `rws-classic`, если качество и лицензия подтверждены.

### Veil of Fate by Dajeki

- Статус: кандидат только после ручной проверки.
- Источник: https://dajeki.itch.io/veil-of-fate-mystic-tarot-icons
- Предварительная оценка: темный визуальный стиль, заявлена AI-assisted/CC0, низкий рейтинг/неясные ограничения.
- Форматы из комментария Issue: Major Arcana, suits icons, court icons.
- Перед подключением проверить: лицензию, происхождение изображений, полноту колоды, визуальную читаемость на телефоне.
- Решение для текущей версии: не подключать в UI.

### Tarot pixel assets by Papitas319

- Статус: кандидат на пиксельную тему.
- Источник: https://papitas319.itch.io/tarot-pixel-assets
- Предварительная оценка: может содержать полный набор 78 карт.
- Форматы из комментария Issue: PNG, pixel art, name your own price.
- Перед подключением проверить: лицензию внутри архива, полноту набора, размер файлов, соответствие названий.
- Решение для текущей версии: не подключать в UI.

### Major Arcana Pixel Art Free by jcanabal

- Статус: неполный кандидат.
- Источник: https://jcanabal.itch.io/major-arcana-pixel-art-free
- Предварительная оценка: только 22 старших аркана.
- Форматы из комментария Issue: монохромный pixel art, card back.
- Перед подключением проверить: лицензию и возможность честно обозначить неполную колоду.
- Решение для текущей версии: не подключать в UI, потому что приложение использует 78 карт.

### Major Arcana Tarot Cards in Pixel by ZUNE

- Статус: неполный кандидат.
- Источник: https://starsinabox.itch.io/majorarcana
- Предварительная оценка: только 22 старших аркана, возможны условия атрибуции.
- Форматы из комментария Issue: PNG в нескольких масштабах, card back.
- Перед подключением проверить: README/лицензию, требования атрибуции, полноту набора.
- Решение для текущей версии: не подключать в UI.

### Pixabay / Pexels tarot-like images

- Статус: не является стабильной колодой.
- Предварительная оценка: отдельные изображения могут быть свободными, но это не проверенный полный набор карт.
- Перед подключением проверить: каждый файл отдельно, лицензионные условия, единый стиль и соответствие картам.
- Решение для текущей версии: не использовать как автоматическую колоду.

## Правила подключения будущих наборов

1. Подключать в UI только проверенные наборы с понятной лицензией.
2. Не использовать внешние изображения в runtime.
3. Не подключать неполные наборы как замену полной колоды на 78 карт.
4. Для каждого нового набора фиксировать источник, лицензию и дату добавления.
5. Проверять мобильную ширину около 390 px и отсутствие горизонтальной прокрутки.
