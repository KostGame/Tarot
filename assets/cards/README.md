# Tarot card images

Card images in this folder are local copies of the Rider-Waite-Smith tarot deck images from Wikimedia Commons:

- Source category: https://commons.wikimedia.org/wiki/Category:Rider-Waite-Smith_tarot_deck_(TaionWC)
- Example file page: https://commons.wikimedia.org/wiki/File:RWS_Tarot_00_Fool.jpg
- Related reference: https://en.wikipedia.org/wiki/Rider-Waite_Tarot

The images are used in this static site as educational illustrations of tarot cards. They were downloaded as reduced-size JPEG thumbnails, about 500 px wide, so GitHub Pages can serve them locally without runtime hotlinks to Wikimedia.

The Wikimedia file pages for this set mark the original Rider-Waite-Smith deck images as public domain / Public Domain Mark. Recheck the individual Wikimedia file pages if these assets are reused outside this project.
