# Visconti-Sforza Composite license notes

Date: `2026-05-28`

This local pack is a composite historical pack for the `KostGame/Tarot` static application.

## Historical cards

Most historical assets included in this folder were downloaded from FromOldBooks card pages under `https://www.fromoldbooks.org/ViscontiSforza-TarotCards/`.

The FromOldBooks card pages state that the source image is out of copyright / public domain in the USA and describe the files as royalty-free stock images for all-purpose use with credit requested.

The same 74-card source set is documented by David Madore, who states that the seventy-four Visconti tarot cards are in the Public Domain and can be copied and used freely and for any purpose.

Source note: https://www.madore.org/~david/weblog/d.2003-09-17.0234.html

`swords-03-three.jpg` was added from Wikimedia Commons file page `https://commons.wikimedia.org/wiki/File:Tre_di_spade.jpg`. Commons file metadata lists the file as Public domain, usage terms Public domain, attribution required false, and license template `pd`.

## Fallback cards

Fallback cards are not stored in this folder. The application resolves missing Visconti-Sforza cards through the existing local Rider-Waite-Smith `rws-classic` fallback in `assets/cards/`.

## Reuse caution

Before reusing this asset pack outside this project, re-check the source pages and their current rights text. The project intentionally does not use modern commercial reconstructions, Pinterest/Etsy images, app dumps, torrents, watermarked files, or files without clear rights notes.
